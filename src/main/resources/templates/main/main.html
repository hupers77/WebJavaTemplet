개발 시작 가이드

  1. 신규 화면: controller/ + templates/ + service/repository 복사 후 수정
  2. 메뉴 등록: 시스템관리 > 메뉴관리에서 URL 등록
  3. 공통코드: 시스템관리 > 공통코드관리에서 코드 추가
  4. 목록 표준: Page + Result 규격 준수

프레임워크 원칙

  • 외부 OSS/유료 라이브러리 금지 (Spring + JDK + 순수 CSS/JS만)
  • ORM 금지, JdbcTemplate + Plain SQL
  • 모든 화면은 layout/default 상속
